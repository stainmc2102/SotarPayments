# 📚 Tài liệu SotarPayments

SotarPayments là fork/phát triển tiếp từ [KoraPayments](https://github.com/dduong19208/KoraPayments), nhưng mọi ví dụ dưới đây dùng đúng tên lệnh, permission và file cấu hình của SotarPayments.

| Tài liệu | Nội dung |
|---|---|
| [installation.md](installation.md) | Yêu cầu hệ thống, cài đặt, cấu trúc thư mục dữ liệu |
| [configuration.md](configuration.md) | Giải thích chi tiết từng file cấu hình YAML |
| [commands.md](commands.md) | Toàn bộ lệnh, alias và quyền |
| [discord-store.md](discord-store.md) | Thiết lập bot Discord Auto Buy |
| [placeholders.md](placeholders.md) | Danh sách placeholder PlaceholderAPI |
| [faq.md](faq.md) | Câu hỏi thường gặp & xử lý lỗi |

## Thứ tự cài đặt khuyến nghị

1. Đọc [installation.md](installation.md) và kiểm tra Java 21, Paper/Folia 1.21+.
2. Chọn provider và cấu hình database trong [configuration.md](configuration.md).
3. Kiểm tra lệnh và permission trong [commands.md](commands.md).
4. Chỉ bật Discord Auto Buy sau khi webhook/giao dịch cơ bản đã hoạt động.

Quay lại [README chính](../README.md).
